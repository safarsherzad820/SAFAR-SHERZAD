## هەنگاو ١ — Supabase
1. بچۆ بۆ https://supabase.com/ و هەژمار دروست بکە یان بچۆ ژوورەوە.
2. پڕۆژەیەکی نوێ دروست بکە بە ناوی `safar-sherzad-store`.
3. لە Project Settings > API (یان Connect) ـەوە `Project URL` و `anon/publishable key` وەربگرە.
4. لە `config.js` ئەم دوو بەهایە بگۆڕە:
   - `PASTE_YOUR_SUPABASE_PROJECT_URL_HERE`
   - `PASTE_YOUR_SUPABASE_ANON_OR_PUBLISHABLE_KEY_HERE`
5. تەنها anon/publishable key بەکاربهێنە. **service_role/secret key مەخە ناو فایلەکانی وێب**؛ ئەوە دەتوانێت داتابەیسەکەت بخاتە مەترسییەوە.

## هەنگاو ٢ — داتابەیس
1. لە Supabase بچۆ بۆ SQL Editor.
2. فایل `supabase_setup.sql` بکەرەوە و هەموو کۆدەکە کۆپی بکە.
3. لە SQL Editor دایبنێ و Run بکە.
4. ئەم کارە خشتەی `products` و `orders` و کۆگای وێنەی `product-images` دروست دەکات و RLS policy ـەکان دادەنێت.
